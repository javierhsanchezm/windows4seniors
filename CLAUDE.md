# windows4seniors

A senior-friendly Windows 11 Home setup, Home launcher and brain trainer for elderly
parents. See `docs/PLAN.md` for the plan and the decisions made so far.

## Git workflow

- **Work directly on `main`.** Do not create feature branches or pull requests.
- Commit each change to `main` and push it with `git push origin main`.
- If a session starts on another branch, switch to `main` first
  (`git fetch origin main && git checkout main && git pull origin main`).
