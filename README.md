# windows4seniors

A simple, safe, large-print Windows 11 Home setup for elderly parents:

- A restricted Home screen with a few apps: Outlook, WhatsApp, YouTube, Word,
  Excel, Chrome, and fixed newspaper pages
- Bigger text, a simpler mouse, and no pop-ups
- Hearing aids connected to the PC
- A daily memory, attention and language trainer

See **[docs/PLAN.md](docs/PLAN.md)** for the full plan and roadmap.
